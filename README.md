# Rolling-Dice

> A simple, clean and fun dice rolling game built with HTML, CSS, and JavaScript.

---

## Features 

- 2 Dice with real faces (⚀, ⚁, ⚂, ⚃, ⚄, ⚅)
- SHake animation while rolling
- Total counter
- Roll History
- Fully responsive - works on mobile
- Modern fintech card desgin
